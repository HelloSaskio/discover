# Saski’O Discover

The enquiry site for Saski’O (experience-led travel): homepage, three-step enquiry form, privacy notice and confirmation.

- `docs/` — the website (hosted free on GitHub Pages). No customer data is stored here.
- `apps-script/Code.gs` — copy of the Google Apps Script that saves each enquiry to the Saski’O enquiry register (Google Sheets) and sends the notification and acknowledgement emails. The live version runs in the hello.saskio Google account.


Enquiries go straight from a visitor’s browser to the Google Apps Script web app; they are never written to this repository.
